# 0010 Test a new post by comparing the final posts, without source matching and without a pass line

**Situation.** The verifier scores a reproduction by whether each original unit was re-found through the same primary source. For the user what matters is the final post: its development, its facts, its depth. Source overlap is a means, and with the generalized profile it is not the question. Two new posts by the same author (not profile material) were the test.

**Decision.** A comparison worker reads the original post and the reproduced post, splits the original into development units itself, and writes `comparison.md` with eleven fixed keys: units covered by substance (sources irrelevant), facts matched and conflicting, fabricated facts (the verifier's definition), depth of both chains, extra links, validity, profile hash. `rek compare-summary` copies the values into one line per run and issues no verdict; the user reads the report and judges. The contact rules (author domains, post-date content, late sources) stay and are checked by the comparison worker, so the "report immediately" gate still works. The original side needs no tracing: the orchestrator writes the four start lines of `units.md`, the one judgment it makes, and `rek prior` is not run.

**Rejected options.** An A/B of old profile vs new profile: the user wanted the existing profile upgraded, and the old version is in git. Reusing the verifier: its unit match requires the same primary source, which the user ruled out. A numeric pass line: a sample of two posts cannot carry one.

**Result.** 224314709934 (containers and the port, 2026-06-14): units 11/24, facts 21/101 (2 conflicting), fabricated 6, depth 20→17, extra 15, valid. 223137359486 (heavy rare earths, 2023-06-26): units 6/22, facts 16/142 (7 conflicting), fabricated 5, depth 17→12, extra 11, valid. Both reproductions are long on the forward chain (carriers, port fees, trade history, contracts) and short on the original's backward detail (the trucking fines, the Vietnam War logistics, Greenland, Myanmar's politics, the bacterial separation, Starship and the space-resource law). Fabrications are again mostly image captions and "first"/"largest" qualifiers.
